# Связка γ̇↔τc, консистентный тангенс и скорость — ревью фикса из `HARDENING_RATE_DEPENDENCE.md`

Дата: 2026-09-26. Файл к замене: `cp_model/Grain.hpp` (`cp_umat.cpp` не меняется, публичный интерфейс `Grain` тот же).

---

## 0. Коротко

1. **Диагноз агента верен по сути**: фиксированная итерация γ̇↔τc_eff с 3 sweep'ами расходится при усилении
   g = n·h·Δγ/τc > 1, и результат определяется произвольным последним sweep'ом. Уточнение: это зависимость
   **от размера шага** (Δε на подшаг), а не от скорости. Модель по построению rate-independent
   (γ̇ = γ̇₀·D_eq·(τ/τc)ⁿ ⇒ Δγ зависит только от Δε). Проверено побитово: при одном и том же Δε и dt,
   отличающемся в 100 раз, результат совпадает до последнего знака; при одинаковой скорости и разном Δε — нет.
2. **Фикс агента исправляет значения, но не тангенс, и он в 3–10 раз медленнее**:
   - `R_all` (латентная часть q·Σⱼ hⱼ·Gⱼ) вычисляется **до** цикла по sweep'ам, когда `G_prev = 0`, т.е. всегда
     равна нулю — латентный член в `G = ∂γ̇/∂σ` полностью потерян (при q = 2 это доминирующий член);
   - `G` строится ≤4 проходами той же рекурсии — это усечённый ряд Неймана для (I + g·…)⁻¹, который при g > 1
     расходится. То есть в режиме, ради которого делался фикс, производная — мусор.
3. **Главная находка: тангенс в пластическом подпространстве был неверен во всех версиях** — и в старой,
   и в агентской. Одноосный касательный модуль E_t = 1/(C⁻¹)₃₃ (аналитический) ≈ 1–3 МПа против 120–740 МПа
   по конечным разностям — упрочнение в тангенс не попадало. **Это ошибка и моего прошлого ревью**
   (`INCREMENT_REVIEW.md` §3: «тангенс корректен, FD-ошибка 3–6e-4»): метрика max|DDSDDE−FD|/max|DDSDDE|
   нормировалась на объёмный упругий блок (~8e4 МПа) и не видела пластический модуль (сотни МПа).
   Там же, в `PERF_REVIEW.md`, я приписал зависимость от шага ошибке обратного Эйлера — по факту большую её
   часть давала несошедшаяся связка.
4. **Почему итерация расходится — не только плохой метод.** При q = 2 матрица H = h·(2·𝟙𝟙ᵀ − I)
   знаконеопределена (собственное значение −h на подпространстве ⊥𝟙). Якобиан связки
   J = I + n·Δt·diag(1/τc)·H·diag(γ̇) для двух равных систем имеет собственные числа 1+3g и **1−g**: при g ≥ 1
   шаг BE теряет единственность (одна система «запирает» соседнюю латентным упрочнением или наоборот).
   Значит, кроме хорошего решателя нужен **контроль g** на подшаге.

## 1. Что изменено в `Grain.hpp`

| # | Изменение | Зачем |
|---|---|---|
| 1 | Связка решается **Ньютоном по y = ln γ̇** (активные системы τ>0), line search Армихо; для KM τc_eff считается за O(n) | квадратичная сходимость при любом g < 1; невязка в лог-единицах O(1) даже при n = 50 |
| 2 | **Точная неявная производная** G = diag(γ̇)·J⁻¹·diag(n/τ)·Ms и ∂Dp/∂ln rf = Σ MsE·γ̇·(J⁻¹𝟙) из той же LU | консистентный тангенс; поправка на зависимость rf от D теперь учитывает упрочнение (было c = P·Dp) |
| 3 | Цепочка тангенса через подшаги переносит **dτc/dε** (`St_buf`, n×6), а не только dσ/dε | без неё при N подшагах E_t ≈ 1/N от истинного |

| 5 | **Предел усиления** g = max n·Δt·hₐ·γ̇ₐ/τcₐ ≤ 0.5 (`CP_GAIN_MAX`); при превышении подшаг сразу делится на ⌈g/0.35⌉ частей | единственность шага BE при q > 1 |

## 3. Ответы на вопросы из `HARDENING_RATE_DEPENDENCE.md` §6

1. **Корректен ли способ решения связки?** Для значения — да, демпфирование находит неподвижную точку.
   Для производной — нет: `G` нельзя получать фиксированным числом проходов рекурсии (плюс баг с `R_all`).
   Нужен Ньютон и неявная производная из его якобиана — сделано.
2. **Критерий 1e-7 по max|Δln γ̇|** для значения достаточен; тангенс ломался не из-за критерия. В новой версии
   критерий 1e-11 в лог-единицах — дёшево при квадратичной сходимости.
3. **Производительность.** Одна точка: на уровне старой версии, в 3.5–8 раз быстрее агентской; мини-МКЭ —
   в 8–9 раз быстрее агентской. Альтернатива «ограничивать подшаг по усилению» реализована как пункт 5 §1,
   но не вместо Ньютона, а вместе с ним.
4. **Изменение результатов.** Относительно старой версии напряжения в поликристалле при типичных шагах
   вырастут примерно вдвое (как у агентской версии); относительно агентской — в пределах 0.3%.
   Все валидации, прогнанные до фикса агента (343el, Neper, полюсные фигуры), нужно перепрогнать.

## 4. Известные ограничения (не блокируют)

- **Явная H внутри подшага** — смещение +0.4% на каждые 1e-3 подшага в раннем транзиенте (§2.1). Лечится
  `/DCP_DS_CRIT_IMPL=1e-3` (медленнее) или неявной H (τc_eff в H) — это отдельная работа.
- **Поворот в тангенсе — первого порядка** по подшагам: на самом первом инкременте Δε = 5e-3 со случайной
  ориентацией, где E_t ≈ 0 (разупрочнение от поворота), ошибка до 30% от E_t (~180 МПа абсолютных на фоне
  упругих 1e5). При Δε ≤ 4e-3 — ≤ 5e-4.
- **hard_mode = 1**: цепочка dΓ/dε через подшаги не реализована — тангенс точен при одном подшаге.
  hard_mode = 0 и 2 — полностью.
- **`rot_mode = 0` в UMAT некорректен** для неединичной ориентации: в `Simulate_Step` при `rot_mode == 0`
  `L` не переводится в КСК, а `get_stress_lab()` поворачивает напряжение. Сейчас не используется — стоит
  либо запретить в `build_params`, либо исправить.

`__declspec(thread)` на `thread_local`.

```

./uniax 0.005 5e-4 0.1 i      # fast, identity   (dt, Δε33, ε_end, i|r)

./fd 5e-4 r                   # тангенс: E_t аналитический vs FD  [rot_mode]

```
