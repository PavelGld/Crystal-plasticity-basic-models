# Дизайн: Неявная схема интегрирования (Newton–Raphson)

Дата: 2026-07-26
Ветка реализации: `implicit-integration` (от `macrolevel`)
Статус: согласовано, ожидает реализации

## 1. Контекст и цели

Текущая явная упруговязкопластическая схема (`check_elastic` / `find_SS`) стабильна только при мелком шаге: закон Хатчинсона с `n_power = 50` делает задачу жёсткой, поэтому применяется адаптивное подшагивание по `DS_CRITICAL = 1.7e-6`.

**Конечная цель проекта:** встраивание модели в Abaqus/Standard как UMAT (поликристалл или монокристалл на точку интегрирования — оба режима перспективны).

**Цель данного этапа:** неявное ядро интегрирования + консистентный алгоритмический тангенс в чистом C++, без UMAT-обёртки. Ядро проектируется UMAT-совместимым: вход — инкремент деформации Δε и dt, выход — σ и ∂Δσ/∂Δε.

### Решения по скоупу (зафиксированы при brainstorm)

- Формулировка Ньютона: **по напряжениям σ (6×6)**, не по Δγ^α. Гладкий вязкопластический закон не требует active set; тангенс получается из финального якобиана.
- Явная схема **сохраняется** как регрессионный эталон, переключение через `integ_mode` в файле материала.
- `Simulate_Step_Soft` (мягкое нагружение): **не работает и не трогаем** — известно нерабочее состояние, отдельная будущая задача.
- Обновление F в `Grain` через `exp(dt·L_КСК)` — **осознанная конвенция**, не баг: всё состояние зерна определено в подвижной КСК; макро-аффинор F_av считается отдельно на уровне RVE в ЛСК. Не меняем.

## 2. Математическая формулировка

### 2.1 Постановка шага

Вход (на подшаг): Δε в нотации Фойгта (инженерной, КСК), dt, состояние на tₙ: σₙ, τc^α, γ^α, ориентация.

Trial-напряжение: σ_tr = σₙ + P:Δε

Невязка:

```
R(σ) = σ − σ_tr + Δt · P : Dᵖ(σ) = 0
Dᵖ(σ) = Σ_α γ̇^α(τ^α) · M_s^α,   τ^α = σ : M_s^α
γ̇^α = γ̇₀ · D_eq · (τ^α / τc^α)^n     при τ^α > 0, иначе 0
```

**Чистый степенной закон без порога** (решение от 2026-07-26, заменяет исходный вариант «порог как в явной схеме»). Причина: пороговый закон разрывен на τ = τc (скачок γ̇ от 0 до γ̇₀·D_eq), из-за чего невязка Ньютона не имеет корня в переходном режиме упруго-пластической границы — подтверждено трассировкой итераций при реализации (полки невязки = расстояние до границы, fallback не помогает). Чистый степенной закон гладок (γ̇ и ∂γ̇/∂τ → 0 при τ → 0), является стандартом Хатчинсона и CP-UMAT, и даёт корректный консистентный тангенс. Цена: подпороговая ползучесть, при n = 50 мала (5e-3·γ̇₀·D_eq при τ = 0.9·τc); эквивалентность с референсными кривыми явной схемы проверяется тестами (допуск 5%). Явная схема сохраняет пороговый закон без изменений. Соглашение об удвоенных системах (±b) сохраняется: вклад только от τ^α > 0.

### 2.2 Якобиан

```
J = I + Δt · P : Σ_α (∂γ̇^α/∂τ^α) · M_s^α ⊗ M_s^α  +  члены упрочнения

∂γ̇^α/∂τ^α  = n · γ̇^α / τ^α
∂γ̇^α/∂τc^α = −n · γ̇^α / τc^α
```

Упрочнение — fully implicit: Δτc^α = Σ_β H^{αβ}·Δγ^β; связка ∂Δγ/∂σ берётся с предыдущей итерации Ньютона (приближение Калидинди, сохраняет практическую квадратичную сходимость).

- hard_mode = 0: члены отсутствуют.
- hard_mode = 1: τc одинаково для всех систем, τc = τc0 + a·(Σγ)^b; производная ∂τc/∂γ_tot = a·b·(γ_tot)^(b−1).
- hard_mode = 2: Kocks–Mecking, матрица H как в явной схеме.

### 2.3 Цикл Ньютона

1. σ ← σ_tr; вычислить R, J.
2. Решить J·δσ = −R (`PartialPivLU`, 6×6).
3. σ ← σ + δσ с **line search Армихо** по ‖R‖ (до 5 откатов) — обязательно при n = 50.
4. Сходимость: ‖R‖ < tol·‖σ_tr‖, tol = 1e-10, макс. 20 итераций.

Защита от переполнения: кламп γ̇ ≤ γ̇_max и ограничение аргумента pow (τ/τc ≤ (γ̇_max/γ̇₀/D_eq)^(1/n)).

Fallback при несходимости: инкремент делится пополам, решаются два полушага рекурсивно (глубина ≤ 8) — аналог PNEWDT в Abaqus.

### 2.4 После сходимости

- γ^α += γ̇^α·Δt (по сошедшимся скоростям), обновление τc.
- Ротация решётки — staggered, существующая логика (Ω из γ̇ и W, кватернион вправо). Связь ротации с σ в тангенс не входит (стандартная практика).

### 2.5 Консистентный тангенс

```
∂Δσ/∂Δε = J⁻¹ · P   (на сошедшемся состоянии, КСК, Фойгт)
```

Доступ: `Grain::get_tangent_crystal_into(Matrix6d&)`. Поворот в ЛСК — существующим `computeVoigtRotationInPlace`. Для RVE (Taylor): P_macro = Σ w_g · T_g · P_g · T_g^T.

Параметры Ньютона (tol, max_iter, γ̇_max, backtracks) — `static constexpr` в `Grain`, по стилю `DS_CRITICAL`.

Подшагивание по `DS_CRITICAL` в `Simulate_Step` сохраняется для обоих режимов как внешняя страховка; для неявной схемы порог можно поднять после валидации (отдельный эксперимент, не часть этого этапа).

## 4. Тестирование и валидация

1. **Регрессия:** все 7 существующих тестов проходят без изменений (integ_mode=0 по умолчанию).
2. **Эквивалентность схем (ключевой тест):** неявная схема воспроизводит референсные кривые `hard_loading` и `uniaxial_tension` в том же допуске 5% при том же dt (конфиги с integ_mode=1).
3. **Стабильность на большом шаге:** dt ×10 и ×50 — стабильно, отклонение от кривой ≤ 10%.
4. **Верификация тангенса:** `get_tangent_crystal_into` против центральных конечных разностей по Δε, относительная ошибка < 1e-5 (обязателен — без него тангенс считается несуществующим).
5. **Юнит-тест якобиана:** J против численного дифференцирования R(σ).
6. **Изотропное упрочнение под неявной схемой:** hard_mode=1 + integ_mode=1, монотонный рост τc.

Критерий готовности: пп. 1–6 зелёные.

## 6. Риски и открытые вопросы

- Сходимость при n = 50 и τ ≫ τc: смягчено line search + клампами + fallback; если не хватит — рассмотреть подстановку log(τ/τc).
- Стоимость: 24 системы × якобиан на каждой итерации Ньютона; буферы-члены, аллокаций нет.
- Порог `DS_CRITICAL` для неявной схемы — после валидации возможно поднять (ускорение RVE-расчётов), отдельным решением.
- Мягкое нагружение RVE: не работает, вне скоупа. При возврате к нему — переосмыслить на неявном ядре с итерациями до сходимости.
