## 1. Дефект A — правка ошибочна

В `coupling_jacobian`:

```cpp
double f = npow / tc_eff(i) * dt;        // ← Δt уже здесь
...
J_k(a, b) += f * dxdg * gamma_dot(j);    // J_ab = δ_ab + (n/τc)·Δt·dxdg·γ̇_b
```

Для KM `dxdg = H(i,j)`, и ∂τc_eff_i/∂γ̇_j = Δt·H(i,j) — то есть `dxdg` это производная, **делённая на Δt**,
ровно как написано в комментарии. Для hard_mode=1 ∂τc_eff/∂γ̇_j = a·b·Γ^(b−1)·Δt, значит `dxdg = iso_d` —
было верно. После правки `dxdg = iso_d·dt` якобиан содержит Δt².

Проверка напрямую (hard_mode=1, 12 активных систем, подшаг Δt = 0.1, развитая пластика):

| | `max|J_k − J_FD|` (J_FD — ЦКР невязки по y) | `max|G − G_FD|/max|G_FD|`, G = ∂γ̇/∂σ |
|---|---|---|
| до правки | **2.0e-8** | **2.9e-10** |
| после правки A | 0.48 (при max|J − I| = 0.54: связка почти потеряна) | 0.52 |

Утверждение «Ньютон сходится к неверной точке» тоже неверно: корень определяется невязкой
`coupling_residual`, а якобиан влияет только на скорость сходимости и на производную. Невязка в обоих
вариантах сходится до 1e-12–1e-14, точка одна и та же — ломается только тангенс.

Полный тангенс, hard_mode=1, E_t = 1/(C⁻¹)₃₃ аналитический против FD (обе стороны через обращение):

| версия | 1 подшаг (Δε = 5e-4) | 3 подшага (Δε = 5e-3) |
|---|---|---|
| моя (без B) | 2e-5 | 66% |
| агента (A + B) | **98%** | 33% |
| **агента, A откачена (прислана)** | **2e-5** | **4e-4** (без поворота решётки — 5e-8) |

## 2. Дефект B — принят

Структура верная: X = ∂τc_eff/∂Γ₀, Sτ₀ = X·SΓ₀, Z = J⁻¹·E·Sτ₀, SΓ₁ = SΓ₀ + Δt·Σ dγ̇/dε. С правильным
якобианом (п.1) тангенс hard_mode=1 через подшаги точен (таблица выше). Спасибо — это закрывает
известное ограничение из моего отчёта.

## 3. Метрика: T(2,2) не видит упрочнения

T(2,2) ≈ K + (пластическая добавка), где K = (c11 + 2c12)/3 = 75 857 МПа, а добавка — 80…500 МПа.
Одно и то же состояние (hard_mode=1, Δε = 5e-3), МПа:

| ε | T22 аналит. / FD | T22 − K аналит. / FD | E_t аналит. / FD |
|---|---|---|---|
| версия с правкой A: 0.02 | 76 064 / 76 105 (**5e-4**) | 207 / 248 | 441 / 522 (**16%**) |
| версия с правкой A: 0.10 | 75 935 / 75 971 (**5e-4**) | 78 / 114 | 165 / 246 (**33%**) |
| исправленная: 0.10 | 75 970.8 / 75 970.9 | 114.1 / 114.2 | 245.5 / 245.5 (2e-5) |

Неверный тангенс проходит сравнение по T(2,2) с запасом ×40 к допуску 2%. Тангенс **идеальной
пластичности** (hard_mode=0, упрочнения нет вовсе) отличается от правильного по T(2,2) на 0.65% — тоже
проходит. Старый KM-тест (`5e-3·|T| + 1e7`) слеп по той же причине.

Откуда «115×»: аналитический E_t = 6.57e8 Па сравнили с **FD-значением T(2,2)** = 7.62e10 Па. Это разные
величины. E_t и должен быть в ~100 раз меньше T(2,2) — это пластический модуль против объёмного.

«det = 3.9e53» — артефакт единиц (Па⁶). Число обусловленности тангенса 2e3–6e3 (до ~1e8 только у
идеальной пластичности, где E_t → 0). Обращение теряет ~3–4 знака из 16, этого хватает с запасом.

**Прислан `tests_tangent.cpp`** — два теста на замену `implicit tangent FD` и
`implicit tangent FD isotropic multi-substep`: полный 6×6 FD-тангенс в КСК, сравнение E_t с допуском 1e-3
и проверка, что состояние действительно пластическое (E_t < 0.05·T22). Проверено на трёх версиях:

Файлы материалов подставьте свои (`grain_implicit.txt`, `grain_test_iso_impl.txt`); ориентация зерна должна

## 4. ε ≈ 0.091 — не дефект модели, а устаревший эталон

Эталон — не экспериментальная величина, а вывод этого же кода: 0.0910006 − 0.0900014 = ровно 509 шагов
плоской деформации с текущим D_eq = √(4/3)·ε̇·dt. То есть эталоны сгенерированы прогоном этого же кода
(с той же сеткой шагов), но более ранней версией.

Кандидат — исправление первого круга: `P_v(3,3..5,5) = c44 → 2·c44` (в конвенции удвоенных сдвигов
правильно 2·c44). На монотонном участке напряжение задаёт пластика, а переходный процесс после смены
пути определяется упругой частью. Поэтому симптом одинаков для KM и для изотропного упрочнения, не
зависит от ориентаций и совпадает у явной и неявной схем. Проверка: RVE из 1000 зёрен, KM, тот же путь
(dt = 1e-3, ε̇ = 0.0017), σ_eq в МПа:

| | ε = 0.09 (эталон 64.19) | ε = 0.091 (эталон **55.82**) | ε = 0.3 (эталон 80.26) |
|---|---|---|---|
| `P_v(3,3) = c44` (как до первого круга) | 63.99 | **55.58** | 80.91 |
| `P_v(3,3) = 2·c44` (текущий) | 64.23 | 59.66 | 81.11 |

(rot_mode=2; при rot_mode=1 — 55.73 / 59.32 соответственно.) Старая константа воспроизводит эталон до 0.4%,
текущая даёт те самые +6.8%. Физика: после смены пути σ_eq проходит через провал; с правильной
сдвиговой жёсткостью минимум (~56.4) достигается раньше, к 255-му шагу, и к 509-му напряжение уже
восстанавливается. Шаг 509 попадает на склон, поэтому точка так чувствительна к упругости.

**Что сделать:** заменить эталоны переходной точки на значения текущего кода (у вас KM ≈ 59.6,
iso ≈ 56.9 — перепроверить на ваших файлах RVE) и включить точки обратно. Для полной уверенности
для iso: временно поставить в `MaterialParams` `P_v(3,3) = c3` — должно получиться ≈ 52.8. Точки 0.09
и 0.3 от константы почти не зависят (≤0.4% и ≤0.3%), их трогать не нужно.
